## Representation v1

Method:

`proofline-local-grouping/nearest-components-v1`

For a set of non-overlapping spatial regions on one evidence page:

1. each region chooses exactly one nearest geometric peer;
2. nearest-peer ordering uses page-normalized center distance, then absolute reading-order delta, then deterministic target word order / identity tie-breaks;
3. the directed nearest edges are treated as an undirected graph;
4. connected components are emitted with deterministic IDs and exact `evidence_id` / `spatial_id` lineage.

No numeric distance threshold is fitted or required. Semantic labels and money values are not grouping inputs.

T18 used the same decisive nearest-peer ordering. T19 only appends `relation_id` after `target_region_id`, so it cannot alter an already-resolved T18 peer choice.
