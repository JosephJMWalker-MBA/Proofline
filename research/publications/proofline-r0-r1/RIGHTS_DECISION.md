# Publication Rights Boundary — Proofline R0/R1

**Decision status:** author-side deposit intent, 2026-09-10.  
**Scope:** the first Proofline research report and its research-owned measurement package only.

This file records the publication boundary so that depositing the paper does not silently license unrelated Proofline code or third-party municipal records. It is an operational publication decision, not legal advice about the copyright or public-record status of any third-party source.

## Manuscript

The intended public deposit license for the final author-created manuscript is **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

The license grant becomes operative through the final publication/deposit process; this repository record exists to make that intended choice explicit before publication.

## Measurement package

Research-owned materials created for the benchmark/evaluation process may be deposited under **CC BY 4.0**, including, where applicable:

- benchmark definitions authored for Proofline;
- source-role and evaluation manifests authored for Proofline;
- score/evaluation outputs generated by the Proofline research harness;
- publication artifact manifests;
- claim/evidence matrices;
- methodological notes; and
- the R0 human-review lineage/receipts authored in this project.

The deposit manifest must identify exactly which files are included.

## Third-party municipal source material

Underlying municipal/public-record source bytes are **excluded from the first measurement-package deposit by default**.

The publication may preserve and report:

- public source URLs;
- publisher/native identifiers;
- source roles;
- retrieval timestamps;
- cryptographic hashes;
- evidence locators; and
- other provenance necessary to reconstruct what was evaluated,

without asserting a new license over the underlying third-party records.

A later rights review may authorize redistribution of particular source files, but that is outside this first deposit.

## Proofline software

**No software license is granted or changed by this publication package.**

The Proofline repository currently has no top-level `LICENSE` file. Publishing the manuscript or measurement package must not be interpreted as relicensing the repository source code under CC BY 4.0 or any open-source license.

A future citable software release requires its own explicit licensing decision and release gate.

## Deposit separation

The first publication should therefore use two Zenodo records:

1. **Publication/preprint:** final paper PDF, CC BY 4.0.
2. **Dataset/research-data record:** research-owned measurement package, CC BY 4.0.

The two records should be linked through related identifiers. Neither record should silently absorb the Proofline software repository or third-party municipal source bytes.

## Stop condition

Do not publish a deposit if the Zenodo preview indicates that CC BY 4.0 is being applied to a materially broader set of files than this boundary authorizes.
